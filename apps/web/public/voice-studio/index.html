02 · Nhà cung cấp & giọng

Azure Neural: lựa chọn ưu tiên cho tiếng Việt, cần tài khoản Azure Speech và khóa F0 hoặc trả phí.

Gemini 3.8 Flash TTS xuất WAV. Cần quyền truy cập model TTS và quota tương ứng.

Groq Orpheus hỗ trợ tiếng Anh / tiếng Ả Rập. Giọng tiếng Anh giới hạn 200 ký tự/yêu cầu; không dùng để đọc tiếng Việt.

Chọn giọng miễn phí: Azure Speech F0 công bố hạn mức Neural 500.000 ký tự/tháng (theo điều kiện tài khoản và khu vực). Gemini có hạn mức theo project. Groq TTS không phải phương án tiếng Việt.

API key từ Wikipedia Writer có thể được điền sẵn nếu bạn đã tự bật tùy chọn lưu trên cùng trình duyệt. Khóa Azure không được lưu vào localStorage.
